Lab: Blind XXE with out-of-band interaction via XML parameter entities

В этой лаборатории есть функция "Проверить запас", которая анализирует входные данные XML, но не отображает никаких неожиданных значений и блокирует запросы, содержащие обычные внешние объекты.
Чтобы решить лабораторную задачу, используйте параметр entity, чтобы заставить XML-анализатор выполнить DNS-поиск и HTTP-запрос к Burp Collaborator.
