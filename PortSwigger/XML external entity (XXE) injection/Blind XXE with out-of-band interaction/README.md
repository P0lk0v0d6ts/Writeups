Lab: Blind XXE with out-of-band interaction

В этой лабораторной работе есть функция «Проверка запасов», которая анализирует входные данные XML, но не отображает результат.
Вы можете обнаружить слепую уязвимость XXE, запустив внеполосные взаимодействия с внешним доменом.
Чтобы решить лабораторную задачу, используйте внешний объект, чтобы заставить XML-анализатор выполнить DNS-поиск и HTTP-запрос к Burp Collaborator.
