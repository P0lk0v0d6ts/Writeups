# Описание
Уязвимость XML External Entity (XXE), при которой приложение уязвимо к инъекции внешних сущностей, но не возвращает их значения в HTTP-ответах. Подтверждение эксплуатации и извлечение данных возможны только через инициирование исходящих DNS- и HTTP-запросов от имени сервера к контролируемому атакующим внешнему домену (Burp Collaborator). Парсер XML не отключает обработку внешних сущностей и DTD, что позволяет атакующему заставить сервер выполнить произвольный внешний запрос.

## Риски
- **Скрытая утечка данных**: атака не оставляет следов в HTTP-ответах, WAF и системы мониторинга могут не обнаружить её.
- **Чтение произвольных файлов**: через внешний DTD возможна эксфильтрация содержимого `/etc/passwd`, конфигураций, ключей.
- **SSRF-атаки**: взаимодействие с внутренними сервисами через внешние сущности.
- **DoS**: экспоненциальное расширение сущностей (Billion Laughs) для отказа в обслуживании.

## Рекомендации

- **Отключить обработку внешних сущностей** и DTD в XML-парсере:
    - Java: `factory.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true);`
    - .NET: `XmlReaderSettings.DtdProcessing = DtdProcessing.Prohibit;`
    - Python: `xml.etree.ElementTree` не поддерживает DTD; для `lxml` — `resolve_entities=False`.
- **Использовать безопасные парсеры** с настройками по умолчанию (например, `defusedxml` в Python).
- **Ограничить исходящие соединения** сервера: запретить DNS/HTTP-запросы к внешним доменам на уровне сетевого периметра.
- **Внедрить строгую валидацию** XML-ввода: белые списки схем, отсечение `DOCTYPE`.
- **Включить WAF** с сигнатурами XXE (`<!ENTITY`, `SYSTEM`, `BURP-COLLABORATOR`).
- **Провести аудит** всех XML-эндпоинтов на предмет обработки внешних сущностей.
