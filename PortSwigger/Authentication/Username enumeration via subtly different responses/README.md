Lab: Username enumeration via subtly different responses

Эта лаборатория тонко уязвима для перечисления имени пользователя и атак пароля грубой силы. Он имеет учетную запись с предсказуемым именем пользователя и паролем, которые можно найти в следующих списках слов:

    Имена пользователей-кандидатов
    Пароли кандидатов

Чтобы решить лабораторию, перечислите действительное имя пользователя, совершите пароль этого пользователя, а затем зайдите на страницу его учетной записи.
