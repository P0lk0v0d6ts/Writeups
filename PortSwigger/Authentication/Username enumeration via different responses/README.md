Lab: Username enumeration via different responses

Эта лаборатория уязвима для перечисления имен пользователей и атак пароля грубой силы. Он имеет учетную запись с предсказуемым именем пользователя и паролем, которые можно найти в следующих списках слов:

    Имена пользователей-кандидатов
    Пароли кандидатов

Чтобы решить лабораторию, перечислите действительное имя пользователя, совершите пароль этого пользователя, а затем зайдите на страницу его учетной записи.
