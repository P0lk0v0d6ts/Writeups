Lab: Blind SQL injection with out-of-band interaction

Эта лаборатория содержит уязвимость слепой SQL-инъекции. Приложение использует отслеживающий файл cookie для аналитики и выполняет SQL-запрос, содержащий значение отправленного файла cookie.

SQL-запрос выполняется асинхронно и не влияет на ответ приложения. Однако вы можете инициировать внеполосные взаимодействия с внешним доменом.

Чтобы решить лабораторную задачу, воспользуйтесь уязвимостью SQL-инъекции, чтобы вызвать поиск DNS в Burp Collaborator.
