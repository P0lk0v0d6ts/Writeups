Lab: Blind SQL injection with conditional responses

Эта лаборатория содержит уязвимость слепой SQL-инъекции. Приложение использует отслеживающий файл cookie для аналитики и выполняет SQL-запрос, содержащий значение отправленного файла cookie.

Результаты SQL-запроса не возвращаются, и сообщения об ошибках не отображаются. Но приложение включает в себя Welcome back сообщение на странице, если запрос возвращает какие-либо строки.

База данных содержит другую таблицу, называемую `users` , со столбцами, называемыми `username` и `password` . Вам необходимо воспользоваться уязвимостью слепой SQL-инъекции, чтобы узнать пароль `administrator` пользователя.

Чтобы решить лабораторную задачу, войдите в систему как `administrator` пользователь.
