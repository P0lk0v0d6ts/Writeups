# Описание
Уязвимость «слепой» SQL-инъекции, при которой приложение не возвращает результаты SQL-запроса и не отражает ошибки СУБД, но его ответ изменяется в зависимости от истинности внедрённого условия. Если запрос возвращает строки, в ответе появляется сообщение `Welcome back`.

## Риски
- **Скрытая утечка данных**: нет прямого вывода — WAF и системы мониторинга могут не обнаружить атаку.
- **Компрометация учётных данных**: получение пароля администратора.
- **Полный захват приложения**: управление пользователями, данными, настройками.

## Рекомендации
- **Использовать параметризованные запросы** (prepared statements) для всех SQL-операций.
- **Применять ORM** с автоматическим экранированием.
- **Внедрить строгую валидацию** входных данных: белые списки для cookie и параметров.
- **Ограничить права учётной записи приложения**: запретить доступ к таблицам, не используемым в бизнес-логике.
- **Отключить вывод SQL-ошибок** в production-окружении.
- **Включить WAF** с поддержкой анализа аномальных ответов (boolean-based detection).
- **Провести аудит** всех точек конкатенации пользовательского ввода в SQL-запросы.
- **Внедрить многофакторную аутентификацию** для административных аккаунтов.
