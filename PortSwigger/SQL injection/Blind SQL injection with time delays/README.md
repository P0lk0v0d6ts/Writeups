Lab: Blind SQL injection with time delays

Эта лаборатория содержит уязвимость слепой SQL-инъекции. Приложение использует отслеживающий файл cookie для аналитики и выполняет SQL-запрос, содержащий значение отправленного файла cookie.

Результаты SQL-запроса не возвращаются, и приложение не реагирует по-разному в зависимости от того, возвращает ли запрос какие-либо строки или вызывает ошибку. Однако, поскольку запрос выполняется синхронно, можно инициировать условные временные задержки для вывода информации.

Чтобы решить лабораторную задачу, воспользуйтесь уязвимостью SQL-инъекции, чтобы вызвать 10-секундную задержку.
