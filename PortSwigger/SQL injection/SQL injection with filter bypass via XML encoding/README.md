Lab: SQL injection with filter bypass via XML encoding

Эта лаборатория содержит уязвимость SQL-инъекции в своей функции проверки запасов. Результаты запроса возвращаются в ответе приложения, поэтому вы можете использовать атаку UNION для извлечения данных из других таблиц.

База данных содержит `users` таблицу, в которой указаны имена пользователей и пароли зарегистрированных пользователей. Чтобы решить лабораторную задачу, выполните атаку с использованием SQL-инъекции, чтобы получить учетные данные пользователя-администратора, а затем войдите в его учетную запись.
