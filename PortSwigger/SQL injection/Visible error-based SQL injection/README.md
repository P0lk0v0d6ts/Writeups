Lab: Visible error-based SQL injection

Эта лаборатория содержит уязвимость SQL-инъекции. Приложение использует отслеживающий файл cookie для аналитики и выполняет SQL-запрос, содержащий значение отправленного файла cookie. Результаты SQL-запроса не возвращаются.

База данных содержит другую таблицу, называемую `users` , со столбцами, называемыми `username` и `password` . Чтобы решить лабораторную задачу, найдите способ раскрыть пароль `administrator` пользователя, а затем войдите в его учетную запись.
