# Описание
Уязвимость позволяет внедрять конструкцию `UNION SELECT` с обращением к системному представлению `v$version`, которое содержит строку с полным описанием версии Oracle Database.
## Обнаружение/Идентификация
В ходе анализа веб-приложения была установлена SQL инъекция среднего уровня.  
Используя SQL-конструкцию `' UNION SELECT 'abc' FROM dual--` была вызвана ошибка Internal Server Error.

## Риски
- **Раскрытие точной версии и патч-уровня СУБД** — атакующий подбирает публичные эксплойты под конкретную версию Oracle.
- **Эскалация атаки** — знание версии позволяет перейти к эксплуатации известных уязвимостей СУБД (например, повышение привилегий через PL/SQL-пакеты).
- **Компрометация всей базы данных** — при наличии прав на чтение системных представлений возможна дальнейшая утечка таблиц и учётных записей.
## Рекомендации
- **Внедрить строгую валидацию** входных данных: белые списки для полей фильтрации, отсечение специальных символов (`'`, `--`, `UNION`).
- **Ограничить права учётной записи приложения** — запретить чтение системных представлений (`v$version`, `v$instance`, `all_tables`).
- **Включить WAF** для блокировки классических SQL-инъекций и сигнатур `UNION SELECT`.
