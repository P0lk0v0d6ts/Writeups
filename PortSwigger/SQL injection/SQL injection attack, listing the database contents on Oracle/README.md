Lab: SQL injection attack, listing the database contents on Oracle

Эта лаборатория содержит уязвимость SQL-инъекции в фильтре категорий продуктов. Результаты запроса возвращаются в ответе приложения, поэтому вы можете использовать атаку UNION для извлечения данных из других таблиц.
Приложение имеет функцию входа в систему, а база данных содержит таблицу, в которой хранятся имена пользователей и пароли. Вам необходимо определить имя этой таблицы и содержащиеся в ней столбцы, а затем получить содержимое таблицы, чтобы получить имя пользователя и пароль всех пользователей.
Чтобы решить лабораторную задачу, войдите в систему как `administrator` пользователь.
