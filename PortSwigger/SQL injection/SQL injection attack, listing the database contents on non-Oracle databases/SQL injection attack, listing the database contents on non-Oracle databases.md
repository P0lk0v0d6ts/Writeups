# Описание
SQL-запросы формируются путем прямой конкатенации пользовательского параметра. Внедрение конструкции `UNION SELECT` позволяет обращаться к представлениям `information_schema`, чтобы получить список таблиц и столбцов.
## Обнаружение/Идентификация
Опытным путем была обнаружена уязвимость позволяющая Исполнителю получить пароль пользователя `administrator`.

## Риски
- **Утечка учётных данных** — атакующий получает логины и пароли/хеши, что ведёт к компрометации аккаунтов.
- **Полное раскрытие схемы БД** — становится известна структура всех таблиц и связей.
## Рекомендации
- **Использовать параметризованные запросы** (prepared statements) для всех SQL-операций.
- **Применять ORM** с автоматическим экранированием.
- **Внедрить строгую валидацию** входных данных: белые списки для полей фильтрации.
- **Ограничить права учётной записи приложения** — запретить доступ к `information_schema` и системным таблицам.
