Lab: Blind SQL injection with out-of-band data exfiltration

Эта лаборатория содержит уязвимость слепой SQL-инъекции. Приложение использует отслеживающий файл cookie для аналитики и выполняет SQL-запрос, содержащий значение отправленного файла cookie.

SQL-запрос выполняется асинхронно и не влияет на ответ приложения. Однако вы можете инициировать внеполосные взаимодействия с внешним доменом.

База данных содержит другую таблицу, называемуюusers , со столбцами, называемыми `username` и `password` . Вам необходимо воспользоваться уязвимостью слепой SQL-инъекции, чтобы узнать пароль `administrator` пользователя.

Чтобы решить лабораторную задачу, войдите в систему как `administrator` пользователь.
