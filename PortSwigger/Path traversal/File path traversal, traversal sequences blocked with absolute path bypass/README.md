Lab: File path traversal, traversal sequences blocked with absolute path bypass

В этой лаборатории обнаружена уязвимость обхода пути при отображении изображений продуктов.

Приложение блокирует последовательности обхода, но рассматривает предоставленное имя файла как относящееся к рабочему каталогу по умолчанию.

Чтобы решить лабораторную задачу, извлеките содержимое/etc/passwd файла.
