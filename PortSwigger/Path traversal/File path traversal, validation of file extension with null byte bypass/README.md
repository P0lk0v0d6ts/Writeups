Lab: File path traversal, validation of file extension with null byte bypass

В этой лаборатории обнаружена уязвимость обхода пути при отображении изображений продуктов.

Приложение проверяет, что предоставленное имя файла заканчивается ожидаемым расширением файла.

Чтобы решить лабораторную задачу, извлеките содержимое/etc/passwd файла.
