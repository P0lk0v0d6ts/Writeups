Lab: File path traversal, traversal sequences stripped non-recursively

В этой лаборатории обнаружена уязвимость обхода пути при отображении изображений продуктов.

Перед использованием приложение удаляет последовательности обхода пути из указанного пользователем имени файла.

Чтобы решить лабораторную задачу, извлеките содержимое/etc/passwd файла.
