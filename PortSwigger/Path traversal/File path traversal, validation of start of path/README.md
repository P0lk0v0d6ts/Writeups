Lab: File path traversal, validation of start of path

В этой лаборатории обнаружена уязвимость обхода пути при отображении изображений продуктов.

Приложение передает полный путь к файлу через параметр запроса и проверяет, что предоставленный путь начинается с ожидаемой папки.

Чтобы решить лабораторную задачу, извлеките содержимое/etc/passwd файла.
