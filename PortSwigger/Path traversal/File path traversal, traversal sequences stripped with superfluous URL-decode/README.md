Lab: File path traversal, traversal sequences stripped with superfluous URL-decode

В этой лаборатории обнаружена уязвимость обхода пути при отображении изображений продуктов.

Приложение блокирует входные данные, содержащие последовательности обхода пути. Затем он выполняет URL-декодирование входных данных перед их использованием.

Чтобы решить лабораторную задачу, извлеките содержимое/etc/passwd файла.
