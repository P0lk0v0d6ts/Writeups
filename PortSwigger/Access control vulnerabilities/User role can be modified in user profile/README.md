Lab: User role can be modified in user profile

 В этой лаборатории есть админ-панель в /admin. Он доступен только для зарегистрированных пользователей с roleid из 2.

Решите лабораторию, получив доступ к панели администратора и используя ее для удаления пользователя carlos.

Вы можете войти в свою учетную запись, используя следующие учетные данные: wiener:peter
