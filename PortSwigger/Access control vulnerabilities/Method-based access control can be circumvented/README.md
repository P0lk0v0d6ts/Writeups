Lab: Method-based access control can be circumvented

Эта лаборатория реализует элементы управления доступом, частично основанные на HTTP-методе запросов. Вы можете ознакомиться с панелью администратора, войдя в систему, используя администратор учетных данных: admin.

Чтобы решить лабораторию, войдите в систему, используя сосиску учетных данных: Peter и используйте ущербные элементы управления доступом, чтобы продвинуть себя, чтобы стать администратором.
