Lab: URL-based access control can be circumvented

Этот веб-сайт имеет неаутентифицированную админ-панель в /admin, но интерфейсная система была настроена для блокировки внешнего доступа к этому пути. Однако серверное приложение построено на основе фреймворка, поддерживающего заголовок X-Original-URL.

Чтобы решить лабораторию, получите доступ к панели администратора и удалите пользователя carlos.
