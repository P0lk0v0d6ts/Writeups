# Описание
PortSwigger Web Security Academy [PortSwigger Academy](https://portswigger.net/web-security) - бесплатные курсы и лабораторные по веб‑безопасности.
По сути, это микс из теории и интерактивных лабораторий (labs), где можно сразу применить знания.
- Теория. Подробно разбираются, как возникают разные уязвимости и как их эксплуатируют.
- Лаборатории. Ты получаешь уязвимое веб-приложение и задачу: найти и эксплуатировать конкретную уязвимость. Например, разобраться с SQL-инъекцией, XSS, CSRF, SSRF, проблемами контроля доступа, аутентификации или бизнес-логики. Для каждой темы есть задания разного уровня сложности: Apprentice (начинающий), Practitioner (практик), Expert (эксперт).
