Lab: Web shell upload via obfuscated file extension

Эта лаборатория содержит уязвимую функцию загрузки изображений. Некоторые расширения файлов внесены в черный список, но эту защиту можно обойти с помощью классической техники обфускации.

Чтобы решить лабораторию, загрузите базовую веб-оболочку PHP, а затем используйте ее для извлечения содержимого файла /home/carlos/secret. Отправьте эту тайну, используя кнопку, указанную в лабораторном баннере.

Вы можете войти в свою учетную запись, используя следующие учетные данные: wiener:peter
