Lab: Remote code execution via web shell upload

Эта лаборатория содержит уязвимую функцию загрузки изображений. Он не выполняет никаких проверок файлов, которые пользователи загружают перед хранением их в файловой системе сервера.

Чтобы решить лабораторию, загрузите базовую веб-оболочку PHP и используйте ее для извлечения содержимого файла /home/carlos/secret. Отправьте эту тайну, используя кнопку, указанную в лабораторном баннере.

Вы можете войти в свою учетную запись, используя следующие учетные данные: wiener:peter
