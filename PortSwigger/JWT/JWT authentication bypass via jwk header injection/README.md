Lab: JWT authentication bypass via jwk header injection

Эта лаборатория использует механизм на основе JWT для проведения сеансов обработки. Сервер поддерживает jwk параметр в заголовке JWT. Это иногда используется для встраивания правильного проверочного ключа непосредственно в токен. Тем не менее, он не проверяет, исходил ли предоставленный ключ из надежного источника.

Чтобы решить лабораторию, измените и подпишите JWT, который дает вам доступ к панели администратора в /admin, затем удалите пользователя carlos.
