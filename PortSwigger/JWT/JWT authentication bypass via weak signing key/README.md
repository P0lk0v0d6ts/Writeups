Lab: JWT authentication bypass via weak signing key

Эта лаборатория использует механизм на основе JWT для проведения сеансов обработки. Он использует чрезвычайно слабый секретный ключ как для знака, так и для проверки токенов. Это может быть легко грубым, используя словосписок общих секретов.

Чтобы решить лабораторию, сначала грубияна, заставьте секретный ключ веб-сайта. После того, как вы получили это, используйте его для подписания модифицированного сессионного токена, который дает вам доступ к панели администратора в /admin, а затем удалите пользователя carlos.
