Lab: Blind OS command injection with time delays

В этой лабораторной работе обнаружена уязвимость слепого внедрения команд ОС в функцию обратной связи.

Приложение выполняет команду оболочки, содержащую предоставленные пользователем данные. Выходные данные команды не возвращаются в ответе.

Чтобы решить лабораторную задачу, воспользуйтесь уязвимостью слепого внедрения команд ОС, чтобы вызвать 10-секундную задержку.
